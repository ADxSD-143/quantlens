═══════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════

❌ PROBLEM: PORT 8501 ALREADY IN USE?

Agar error aaye "Address already in use", to naya port use karo:

───────────────────────────────────────────────────────────────────────────
streamlit run app.py --server.port 8502
───────────────────────────────────────────────────────────────────────────

Phir browser me jaao:
  http://localhost:8502

═══════════════════════════════════════════════════════════════════════════

❌ PROBLEM: ModuleNotFoundError (import nahi hora)

Terminal me yeh likho:

───────────────────────────────────────────────────────────────────────────
pip install -r requirements.txt
───────────────────────────────────────────────────────────────────────────

Wait 5-10 minutes. Phir:

───────────────────────────────────────────────────────────────────────────
streamlit run app.py
───────────────────────────────────────────────────────────────────────────

═══════════════════════════════════════════════════════════════════════════

❌ PROBLEM: Pandas error?

Terminal me likho:

───────────────────────────────────────────────────────────────────────────
pip uninstall -y pandas
pip install pandas
───────────────────────────────────────────────────────────────────────────

Phir:

───────────────────────────────────────────────────────────────────────────
streamlit run app.py
───────────────────────────────────────────────────────────────────────────
